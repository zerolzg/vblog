基础概念

变量

基础类型

  1. 整型（int）：Python 中可以处理任意大小的整数，而且支持二进制（如0b100，换算成十进制是 4）、八进制（如0o100，换算成十进制是 64）、十进制（100）和十六进制（0x100，换算成十进制是 256）的表示法。
print(0b100)  # 二进制整数
print(0o100)  # 八进制整数
print(100)    # 十进制整数
print(0x100)  # 十六进制整
  1. 浮点型（float）：浮点数也就是小数，之所以称为浮点数，是因为按照科学记数法表示时，一个浮点数的小数点位置是可变的，浮点数除了数学写法（如123.456）之外还支持科学计数法（如1.23456e2，表示1.23456×102\small{1.23456 \times 10^{2}}1.23456×102）。
print(123.456)    # 数学写法
print(1.23456e2)  # 科学计数

  1. 字符串型（str）：字符串是以单引号或双引号包裹起来的任意文本，比如'hello'和"hello"。

  2. 布尔型（bool）：布尔型只有True、False两种值

作用域

在 Python 中，变量的作用域分为 全局变量 和 局部变量

1. 全局变量（Global Variable）
  • 定义：在函数或类外部定义的变量，作用域覆盖整个模块。
  • 特点：
    • 可在程序任何位置访问（包括函数内部）。
    • 若要在函数内部修改全局变量，需使用 global 关键字显式声明。
    • 不声明直接赋值会创建新的局部变量，而非修改全局变量。

示例：

x = 10  # 全局变量

def func():
    global x  # 声明使用全局变量 x
    x = 20    # 修改全局变量

func()
print(x)      # 输出 20
2. 局部变量（Local Variable）
  • 定义：在函数或类内部定义的变量，作用域仅限于定义它的代码块。
  • 特点：
    • 仅在函数内部有效，函数执行结束后销毁。
    • 若与全局变量同名，函数内优先访问局部变量。

示例：

def func():
    y = 5    # 局部变量
    print(y)  # 输出 5

func()
print(y)      # 报错！y 未定义
3. 作用域规则（LEGB 规则）

Python 查找变量的顺序为：

  1. L（Local）：局部作用域（如函数内部）。
  2. E（Enclosing）：嵌套函数的外层作用域（闭包）。
  3. G（Global）：全局作用域。
  4. B（Built-in）：内置作用域（如 len、print 等）。

示例：

x = "global"  # 全局变量

def outer():
    x = "outer"  # 外层作用域
    def inner():
        x = "inner"  # 局部作用域
        print(x)     # 输出 "inner"
    inner()

outer()
print(x)  # 输出 "global"
4. 修改嵌套作用域的变量

若要在嵌套函数中修改外层非全局变量，需使用 nonlocal 关键字：

def outer():
    x = 10
    def inner():
        nonlocal x  # 声明使用外层变量 x
        x = 20
    inner()
    print(x)  # 输出 20

outer()
5. 可变对象（如列表、字典）的特殊性
  • 直接修改内容：无需使用 global 或 nonlocal。
  • 重新赋值：需使用 global 或 nonlocal。

示例：

my_list = [1, 2, 3]  # 全局可变对象

def modify_list():
    my_list.append(4)  # 直接修改内容，无需声明

modify_list()
print(my_list)  # 输出 [1, 2, 3, 4]

def replace_list():
    global my_list
    my_list = [5, 6]  # 重新赋值，需声明

replace_list()
print(my_list)  # 输出 [5, 6]
6. 关键总结
场景行为
访问全局变量直接使用，无需声明（除非需要修改）
修改全局变量必须使用 global 声明
修改嵌套作用域变量必须使用 nonlocal 声明
可变对象的内容修改无需声明（如 list.append()）
可变对象的重新赋值需声明（如 global 或 nonlocal）
7. 注意事项
  • 避免全局变量滥用：全局变量可能导致代码耦合度高，难以维护。
  • 命名冲突：局部变量与全局变量同名时，局部变量会遮蔽全局变量。
  • 默认参数陷阱：默认参数在函数定义时创建，若为可变对象，多次调用可能共享同一对象。

分支/循环

  1. 分支结构可以使用if、elif和else三个关键字。

  2. 使用match和case 关键字。

  3. 明确知道循环执行的次数，使用for-in循环，反之使用while循环；使用break终止循环，也可以在循环结构中使用continue关键字让循环结构直接进入下一轮次。

实例：

  1. 输出斐波那契数列中的前 20 个数
a, b = 0, 1
for _ in range(20):
    a, b = b, a + b
    print(a)
  1. 翻转正整数
num = int(input('num = '))
reversed_num = 0
while num > 0:
    reversed_num = reversed_num * 10 + num % 10
    num //= 10
print(reversed_num)

字符串

1. 核心特性

  • 不可变有序的字符序列，支持 Unicode 字符。
  • 丰富的操作方法：提供大量内置方法用于文本处理。
  • 内存高效：Python 对字符串有优化（如驻留机制），适合高频使用的文本数据。

2. 创建字符串

  • 基础创建：

    s1 = "Hello, World!"     # 双引号
s2 = 'Python'            # 单引号
s3 = """多行
        字符串"""         # 三引号（保留换行和缩进）
s4 = r"C:\new\file"      # 原始字符串（转义符无效）

  • 类型转换：

    s5 = str(100)           # "100"（整数转字符串）
s6 = str([1, 2, 3])     # "[1, 2, 3]"（列表转字符串）

3. 常用操作

访问与切片

s = "abcdef"
print(s[0])      # 'a'（索引从0开始）
print(s[-1])     # 'f'（倒数第一个）
print(s[1:4])    # 'bcd'（切片，左闭右开）
print(s[::-1])   # 'fedcba'（反转）

常用方法

  • 修改类（返回新字符串）：

    s.upper()               # "HELLO"（全大写）
s.lower()               # "hello"（全小写）
s.strip()               # 去除首尾空白符（如换行、空格）
s.replace("l", "x")    # "hexxo"（替换字符）

  • 查找与统计：

    s.find("lo")            # 3（返回首次出现的索引，未找到返回-1）
s.index("lo")           # 3（类似 find，但未找到会报 ValueError）
s.count("l")            # 2（统计出现次数）

  • 判断类：

    s.startswith("He")      # True（是否以指定前缀开头）
s.endswith("d!")        # True（是否以指定后缀结尾）
s.isdigit()             # False（是否全为数字）
s.isalpha()             # True（是否全为字母）

分割与合并

# 分割为列表
parts = "a,b,c".split(",")       # ['a', 'b', 'c']

# 合并列表为字符串
joined = "-".join(["2023", "08", "01"])  # "2023-08-01"

4. 字符串格式化

  • f-string（Python 3.6+ 推荐）：

    name = "Alice"
age = 25
text = f"{name} is {age} years old."  # "Alice is 25 years old."

  • format() 方法：

    "{} + {} = {}".format(2, 3, 5)       # "2 + 3 = 5"
"{1} comes before {0}".format("B", "A")  # "A comes before B"

  • 经典 % 格式化：

    "Price: $%.2f" % 99.956              # "Price: $99.96"

5. 应用场景

  • 文本清洗：

    dirty = "  Extra   spaces   "
clean = dirty.strip().replace("  ", " ")  # "Extra spaces"

  • 数据解析（如 CSV）：

    csv_line = "Alice,25,Engineer"
name, age, job = csv_line.split(",")  # 解包为变量

  • 模板生成：

    html_template = """
<h1>{title}</h1>
<p>{content}</p>
""".format(title="Hello", content="Welcome!")

  • 正则表达式处理：

    import re
text = "Email: user@example.com"
match = re.search(r"\b[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Z|a-z]{2,}\b", text)
if match:
    print(match.group())  # "user@example.com"

6. 注意事项

  1. 不可变性：

    s = "hello"
s[0] = "H"  # 报错！字符串不可直接修改
# 正确做法：创建新字符串
s = "H" + s[1:]  # "Hello"

  2. 编码处理：

    # 字符串与字节转换
data = "中文".encode("utf-8")  # b'\xe4\xb8\xad\xe6\x96\x87'
text = data.decode("utf-8")   # "中文"

  3. 性能陷阱：

    # 避免频繁拼接（低效）
result = ""
for s in ["a", "b", "c"]:
    result += s  # 每次拼接生成新对象
# 高效方式：使用列表+join
parts = []
for s in ["a", "b", "c"]:
    parts.append(s)
result = "".join(parts)

列表

Python 中的列表（list）是一种可变有序容器，支持高效的元素增删查改操作。

1. 创建列表

  • 基础创建：

    a = [1, 2, 3]                 # [1, 2, 3]
b = list()                     # 空列表 []
c = list("abc")                # ['a', 'b', 'c']

  • 列表推导式：

    squares = [x**2 for x in range(5)]  # [0, 1, 4, 9, 16]
evens = [x for x in range(10) if x % 2 == 0]  # [0, 2, 4, 6, 8]

2. 访问元素

  • 索引与切片：

    a = [10, 20, 30, 40]
print(a[1])     # 20（索引从0开始）
print(a[-1])    # 40（倒数第一个）
print(a[1:3])   # [20, 30]（左闭右开）
print(a[::-1])  # [40, 30, 20, 10]（反转）

3. 修改列表

  • 添加元素：

    a.append(50)        # 末尾添加 → [10,20,30,40,50]
a.insert(1, 15)     # 索引1插入 → [10,15,20,30,40]
a.extend([50, 60])  # 合并列表 → [10,20,30,40,50,60]

  • 删除元素：

    a.pop()         # 删除末尾元素 → 50（列表变为[10,20,30,40]）
a.pop(1)        # 删除索引1 → 20（列表变为[10,30,40]）
a.remove(30)    # 删除第一个匹配项 → [10,40]
del a[0:2]      # 删除切片 → [40]
a.clear()       # 清空 → []

4. 常用操作

  • 长度与存在性检查：

    len([1,2,3])          # 3
if 2 in [1,2,3]: ...  # True

  • 排序与反转：

    a = [3, 1, 4, 2]
a.sort()              # 原地排序 → [1,2,3,4]
sorted_a = sorted(a)  # 返回新列表
a.reverse()           # 原地反转 → [4,3,2,1]

  • 其他方法：

    a.index(3)    # 元素3的索引 → 2
a.count(2)    # 元素2出现的次数 → 1

5. 遍历列表

  • 基本遍历：

    for num in [1, 2, 3]:
    print(num)

  • 带索引遍历（enumerate）：

    for index, value in enumerate(['a', 'b', 'c']):
    print(f"Index {index}: {value}")

6. 进阶技巧

  • 浅拷贝与深拷贝：

    a = [1, [2, 3]]
b = a.copy()       # 浅拷贝：嵌套列表仍是引用
import copy
c = copy.deepcopy(a)  # 深拷贝：完全独立副本

  • 多维列表：

    matrix = [[1,2,3], [4,5,6]]
print(matrix[0][1])  # 2

  • 性能注意：

    • 头部操作（如insert(0, x)）效率低（O(n)），推荐用collections.deque。
    • 尾部操作（append/pop）高效（O(1)），适合作为栈使用。

7. 典型应用场景

  • 替代栈：append()入栈，pop()出栈。
  • 替代队列（不推荐）：若需高效队列，使用deque。
  • 动态数据集合：存储可变的同构或异构数据。

元组

1. 核心特性

  • 不可变有序序列，创建后无法修改元素。
  • 元素类型多样：可包含任意数据类型（包括列表、字典等可变对象）。
  • 内存效率：通常比列表更节省内存，适合存储不变数据。

2. 创建元组

  • 基础创建：

    t1 = (1, 2, 3)             # (1, 2, 3)
t2 = ("a", 5, [4, 5])       # 混合类型
t3 = (4,)                   # 单元素元组（必须有逗号）

  • 转换生成：

    t4 = tuple([1, 2, 3])       # 列表转元组 → (1, 2, 3)
t5 = tuple("abc")           # 字符串转元组 → ('a', 'b', 'c')

3. 访问元素

  • 索引与切片（与列表相同）：

    t = (10, 20, 30, 40)
print(t[1])      # 20（正向索引）
print(t[-2])     # 30（反向索引）
print(t[1:3])    # (20, 30)（左闭右开）

  • 拆包（Unpacking）：

    x, y, z = (1, 2, 3)        # x=1, y=2, z=3
a, *rest = (10, 20, 30, 40) # a=10, rest=[20, 30, 40]

  • 命名元组（Named Tuple）（高级用法）：

    from collections import namedtuple
Point = namedtuple("Point", ["x", "y"])
p = Point(3, y=4)           # Point(x=3, y=4)
print(p.x, p.y)             # 3 4

4. 常用操作

  • 长度与存在性检查：

    len((1, 2, 3))         # 3
if 2 in (1, 2, 3): ... # True

  • 统计与索引：

    t = (1, 2, 2, 3)
t.count(2)              # 2（元素出现次数）
t.index(3)              # 3（元素首次出现的索引）

  • 不可变性限制：

    t = (1, [2, 3])
t[1].append(4)          # 允许！元组内的列表可变 → (1, [2, 3, 4])
t[0] = 10               # 报错！元组自身不可修改

5. 应用场景

  • 作为字典的键：

    locations = {(35.7, 139.7): "Tokyo", (40.7, -74.0): "New York"}

  • 函数返回多个值：

    def get_stats(data):
    return min(data), max(data), sum(data)/len(data)

  • 保护数据不变性：

    config = ("localhost", 8080, "read-only")  # 防止配置被意外修改

  • 高效存储常量数据：

    colors = ((255, 0, 0), (0, 255, 0), (0, 0, 255))  # RGB颜色元组

6. 注意

  1. 单元素陷阱：(5) 会被识别为整数，必须写作 (5,)。
  2. 不可变是浅层的：若元组包含可变对象（如列表），这些对象内部仍可修改。
  3. 替代方案：需要不可变且更灵活的结构时，考虑使用 dataclass 或 NamedTuple。

集合

1. 核心特性

  • 可变无序容器，元素唯一，不支持重复。
  • 高效查找：基于哈希表实现，成员检测（in）的时间复杂度为 O(1)。
  • 支持集合运算：并集、交集、差集、对称差集等。

2. 创建集合

  • 基础创建：

    s = {1, 2, 3}                # {1, 2, 3}
s = set()                     # 空集合（不能用 {}，因为 {} 是空字典）
s = set([1, 2, 2, 3])        # 列表转集合 → {1, 2, 3}（自动去重）

  • 集合推导式：

    evens = {x for x in range(10) if x % 2 == 0}  # {0, 2, 4, 6, 8}

3. 修改集合

  • 添加元素：

    s.add(4)           # {1, 2, 3, 4}
s.update([5, 6])   # 批量添加 → {1, 2, 3, 4, 5, 6}

  • 删除元素：

    s.remove(3)        # 删除元素（若不存在则报错 KeyError）
s.discard(10)      # 删除元素（不存在则不报错）
s.pop()            # 随机删除并返回一个元素
s.clear()          # 清空 → set()

4. 集合运算

  • 运算符与方法：

    | 运算 | 运算符 | 方法 | 示例 | | ------------ | ------ | ------------------------ | ----------------------- | ------ | ---------------- | | 并集 | | | union() | {1,2} | {2,3} → {1,2,3} | | 交集 | & | intersection() | {1,2} & {2,3} → {2} | | 差集 | - | difference() | {1,2} - {2,3} → {1} | | 对称差集 | ^ | symmetric_difference() | {1,2} ^ {2,3} → {1,3} |

  • 子集与超集判断：

    a = {1, 2}
b = {1, 2, 3}
a.issubset(b)       # True（a 是 b 的子集）
b.issuperset(a)     # True（b 是 a 的超集）
a.isdisjoint({4,5}) # True（a 与 {4,5} 无交集）

5. 常用方法

  • 长度与存在性检查：

    len({1, 2, 3})          # 3
if 2 in {1, 2, 3}: ...  # True

  • 复制集合：

    s_copy = s.copy()       # 浅拷贝

6. 应用场景

  • 去重：

    lst = [1, 2, 2, 3]
unique = list(set(lst))  # [1, 2, 3]（顺序可能丢失）

  • 高效成员检测：

    valid_users = {"Alice", "Bob", "Charlie"}
if user_input in valid_users: ...

  • 集合运算：

    # 找两个列表的交集
list1 = [1, 2, 3]
list2 = [2, 3, 4]
common = set(list1) & set(list2)  # {2, 3}

7. 不可变集合：frozenset

  • 不可变版本，可哈希（可用作字典键或集合元素）：

    fs = frozenset([1, 2, 3])
d = {fs: "value"}       # 合法

8. 注意点

  1. 无序性：集合元素无固定顺序，无法通过索引访问。
  2. 元素不可变性：集合元素必须是不可变类型（如数字、字符串、元组），不能包含列表或字典。
  3. 性能陷阱：频繁修改集合可能因哈希冲突导致性能下降。

字典

1. 核心特性

  • 键值对容器：存储 key: value 数据，键唯一且不可变（如字符串、数字、元组）。
  • 高效查找：基于哈希表实现，键的查找、插入、删除时间复杂度为 O(1)。
  • 有序性（Python 3.7+）：保持插入顺序，遍历时按插入顺序返回键值对。

2. 创建字典

  • 字面量创建：

    d1 = {"name": "Alice", "age": 25}     # 直接定义键值对
d2 = {}                               # 空字典

  • 构造函数：

    d3 = dict(name="Bob", age=30)         # 关键字参数创建
d4 = dict([("name", "Charlie"), ("age", 35)])  # 列表转字典

  • 字典推导式：

    squares = {x: x**2 for x in range(5)}  # {0:0, 1:1, 2:4, 3:9, 4:16}

3. 访问与修改

  • 通过键访问值：

    print(d1["name"])           # Alice（键不存在会报 KeyError）
value = d1.get("phone", "N/A")  # 安全获取（键不存在返回默认值）

  • 增删改操作：

    d1["city"] = "Paris"        # 添加新键值对
d1["age"] = 26              # 修改值
del d1["city"]              # 删除键值对
age = d1.pop("age")         # 删除并返回值 → 26
d1.update({"age": 27, "job": "Engineer"})  # 合并字典（重复键覆盖）

4. 常用方法

  • 获取键、值、键值对（返回视图对象）：

    keys = d1.keys()        # 所有键的视图（如 dict_keys(['name', 'age'])）
values = d1.values()    # 所有值的视图
items = d1.items()      # 所有键值对的视图

  • 成员检查：

    if "name" in d1: ...    # True

  • 设置默认值：

    d1.setdefault("phone", "123-4567")  # 键存在则返回值，否则设置默认值

  • 清空字典：

    d1.clear()              # 清空 → {}

5. 字典推导式

  • 快速生成字典：

    # 过滤并转换数据
data = {"a": 1, "b": 2, "c": 3}
filtered = {k: v*2 for k, v in data.items() if v > 1}  # {'b':4, 'c':6}

6. 应用场景

  • 结构化数据存储：

    user = {"id": 101, "name": "Alice", "roles": ["admin", "user"]}

  • 快速查找表：

    grades = {"math": 90, "physics": 85}
print(grades["math"])  # 直接通过键获取值

  • 统计词频：

    text = "apple banana apple orange"
words = text.split()
count = {}
for word in words:
    count[word] = count.get(word, 0) + 1
# {'apple':2, 'banana':1, 'orange':1}

  • 配置管理：

    config = {"host": "localhost", "port": 8080, "debug": True}

7. 注意事项

  1. 键不可变：键必须可哈希，列表、字典等可变类型不能作为键。
  2. 覆盖问题：重复赋值会覆盖旧值。
  3. 有序性依赖：Python 3.7+ 才保证插入顺序，低版本需用 collections.OrderedDict。
  4. 内存占用：大量数据时，字典内存开销较高（可用 __slots__ 或第三方库优化）。

8. 进阶技巧

  • 合并字典（Python 3.9+）：

    d = {"a": 1} | {"b": 2}  # {'a':1, 'b':2}

  • 默认值处理（collections.defaultdict）：

    from collections import defaultdict
dd = defaultdict(int)    # 键不存在时默认返回 int() → 0
dd["count"] += 1         # 自动初始化

  • 字典视图动态更新：

    d = {"a": 1}
keys = d.keys()
d["b"] = 2
print(keys)  # 视图自动更新 → dict_keys(['a', 'b'])

函数

1. 基本定义

函数是可重复使用的代码块，用于执行特定任务，通过 def 关键字定义。
核心目标：提高代码复用性、模块化设计和逻辑抽象。

2. 函数的组成要素

def add(a, b):          # 函数名: add，形参: a, b
    """计算两数之和"""   # 文档字符串（docstring）
    result = a + b      # 函数体逻辑
    return result       # 返回值

sum = add(3, 5)         # 调用函数，实参为 3 和 5 → sum=8
组成部分说明
函数名标识函数，需遵循变量命名规则（如 calculate_area）
参数输入值（形参：定义时的参数，实参：调用时传入的值）
函数体执行具体操作的代码块
返回值通过 return 返回结果（默认返回 None）
文档字符串描述函数功能的注释，可通过 __doc__ 访问

3. 函数的核心特性

(1) 参数传递机制

  • 按对象引用传递：

    • 不可变对象（如整数、字符串）传递副本，函数内修改不影响外部。
    • 可变对象（如列表、字典）传递引用，函数内修改会影响外部。
    def modify(num, lst):
    num += 1        # 不影响外部变量（不可变）
    lst.append(4)   # 影响外部列表（可变）

x = 10
my_list = [1, 2, 3]
modify(x, my_list)  # x仍为10，my_list变为[1, 2, 3, 4]
(2) 参数类型
参数类型语法示例说明
位置参数func(a, b)按顺序传递实参
关键字参数func(b=2, a=1)按参数名指定，可打乱顺序
默认参数def func(a, b=5)调用时可省略有默认值的参数
可变参数def func(*args)接收任意数量位置参数（打包为元组）
关键字可变参数def func(**kwargs)接收任意数量关键字参数（打包为字典）
(3) 作用域规则

  • 局部变量：函数内部定义的变量，仅在函数内有效。

  • 全局变量：函数外定义的变量，需用 global 声明修改。

    x = 10  # 全局变量
def change():
    global x
    x = 20  # 修改全局变量

change()    # x变为20

4. 高阶函数特性

(1) 函数作为对象

函数是一等公民，可被赋值、传递或作为返回值：

def greet(name):
    return f"Hello, {name}!"

func = greet          # 赋值给变量
print(func("Alice"))  # 输出：Hello, Alice!
(2) 嵌套函数与闭包

函数内部可定义其他函数，并捕获外部作用域的变量：

def outer():
    msg = "Hi"
    def inner():      # 嵌套函数
        print(msg)    # 捕获外部变量（闭包）
    return inner

closure = outer()
closure()            # 输出：Hi
(3) 装饰器（Decorator）

在不修改原函数代码的情况下增强功能：

def logger(func):
    def wrapper(*args, **kwargs):
        print(f"Calling {func.__name__}")
        return func(*args, **kwargs)
    return wrapper

@logger
def add(a, b):
    return a + b

add(3, 5)  # 输出：Calling add → 结果8

5. 函数的优势

优势说明
代码复用避免重复代码，简化维护
模块化设计将复杂问题分解为小任务，提高可读性
逻辑抽象隐藏实现细节，通过接口调用（如 sum() 无需关注内部如何计算）
参数灵活性支持多种参数传递方式，适应不同场景需求

6. 典型应用场景

  • 封装重复逻辑：如数据清洗、文件操作。
  • 实现算法模块：如排序、搜索算法。
  • 构建 API 接口：通过函数定义服务端点。
  • 扩展功能：通过装饰器添加日志、权限校验等。

7. 注意事项

  1. 单一职责原则：一个函数只做一件事。
  2. 避免副作用：谨慎修改全局变量或可变参数。
  3. 合理命名：函数名应明确表达功能（如 calculate_average）。
  4. 默认参数陷阱：默认参数避免使用可变对象（如 def f(a, lst=[])）。

yield

一、基本概念

  • 生成器函数：使用 yield 的函数称为生成器函数，调用时返回一个生成器对象（Generator），不会立即执行函数体。
  • 惰性求值：生成器按需生成值（每次调用 next() 生成一个值），节省内存，适合处理大数据或无限序列。

二、基本用法

1. 生成器函数定义

def simple_generator():
    yield 1
    yield 2
    yield 3

gen = simple_generator()
print(next(gen))  # 输出: 1
print(next(gen))  # 输出: 2

2. 遍历生成器

for value in simple_generator():
    print(value)  # 输出: 1, 2, 3

3. 生成无限序列

def infinite_counter():
    count = 0
    while True:
        yield count
        count += 1

counter = infinite_counter()
print(next(counter))  # 0
print(next(counter))  # 1

三、高级用法

1. send() 方法：向生成器发送值

def interactive_generator():
    value = yield "Ready to receive"
    yield f"Received: {value}"

gen = interactive_generator()
print(next(gen))          # 输出: "Ready to receive"
print(gen.send("Hello"))  # 输出: "Received: Hello"

2. throw() 方法：向生成器抛出异常

def error_handler():
    try:
        yield "Start"
    except ValueError:
        yield "Caught ValueError"

gen = error_handler()
print(next(gen))               # 输出: "Start"
print(gen.throw(ValueError())) # 输出: "Caught ValueError"

3. close() 方法：终止生成器

gen = infinite_counter()
print(next(gen))  # 0
gen.close()
next(gen)         # 抛出 StopIteration 异常

4. yield from：委托生成器

def sub_generator():
    yield "Sub 1"
    yield "Sub 2"

def main_generator():
    yield "Main 1"
    yield from sub_generator()  # 委托给子生成器
    yield "Main 2"

for item in main_generator():
    print(item)  # 输出: Main 1, Sub 1, Sub 2, Main 2

四、典型应用场景

  1. 处理大文件
    逐行读取文件，避免一次性加载到内存：

    def read_large_file(file_path):
    with open(file_path, 'r') as f:
        for line in f:
            yield line.strip()

  2. 惰性计算
    生成斐波那契数列：

    def fibonacci():
    a, b = 0, 1
    while True:
        yield a
        a, b = b, a + b

  3. 协程（Coroutine）
    通过 send() 实现双向通信：

    def coroutine():
    while True:
        x = yield
        print(f"Received: {x}")

c = coroutine()
next(c)      # 启动生成器
c.send(10)   # 输出: "Received: 10"

五、注意事项

  1. 生成器只能迭代一次
    生成器对象遍历完毕后无法重用，需重新创建。

  2. 性能权衡

    • 优点：内存高效（逐个生成值）。
    • 缺点：速度可能略慢于直接操作列表。

  3. 避免副作用
    生成器函数中慎用全局变量或有副作用的操作。

六、生成器表达式

类似列表推导式，但使用圆括号，返回生成器：

gen = (x**2 for x in range(5))
print(list(gen))  # 输出: [0, 1, 4, 9, 16]

掌握 yield 可以编写高效、灵活的迭代逻辑，尤其适合处理流式数据或大规模计算任务。

序列化

  • 序列化：序列化是指将 Python 对象转换成一个标准格式（如字符串、字节流或文件格式）的过程。这样处理后的数据可以保存到磁盘、数据库中，或通过网络传输给其他程序。常见的序列化格式有 **JSON（文本格式）**和 **pickle（二进制格式）**等

  • 反序列化：反序列化则是序列化的逆过程，即将存储或传输的数据重新转换为原始的 Python 对象。这样就可以在需要时恢复对象的状态和数据结构。

一、json

特点：跨语言文本格式，仅支持基础数据类型（字典、列表、字符串、数字等）。

序列化：json.dump(obj, file) 或 json.dumps(obj)

反序列化：json.load(file) 或 json.loads(data)

import json

data = {"name": "Bob", "age": 25}
json_str = json.dumps(data)  # 转为字符串
loaded = json.loads(json_str)  # 转回字典

二、pickle

特点：Python 专用二进制协议，支持几乎所有对象。

序列化：pickle.dump(obj, file) 或 pickle.dumps(obj)

反序列化：pickle.load(file) 或 pickle.loads(data)

import pickle

data = {"name": "Alice", "age": 30}
# 序列化到文件
with open("data.pkl", "wb") as f:
    pickle.dump(data, f)
# 反序列化
with open("data.pkl", "rb") as f:
    loaded = pickle.load(f)

三、对象序列化

1、使用 __dict__ 和默认参数（适合 JSON）

对于简单对象，可以直接利用对象的 __dict__ 属性配合 json 模块的 default 和 object_hook 参数。

import json

class User:
    def __init__(self, name, age):
        self.name = name
        self.age = age

# 自定义序列化：将对象转为字典
def obj_to_dict(obj):
    return obj.__dict__

# 自定义反序列化：从字典恢复对象
def dict_to_obj(d):
    return User(d["name"], d["age"])

user = User("Alice", 30)

# 序列化
json_str = json.dumps(user, default=obj_to_dict)

# 反序列化
loaded_user = json.loads(
    json_str,
    object_hook=lambda d: User(d["name"], d["age"])
)

2、使用 dataclasses 和 asdict

from dataclasses import dataclass, asdict
import json

@dataclass
class User:
    name: str
    age: int

user = User("Bob", 25)

# 序列化：直接转为字典
user_dict = asdict(user)
json_str = json.dumps(user_dict)

# 反序列化：从字典重建对象
loaded_dict = json.loads(json_str)
loaded_user = User(**loaded_dict)

collections

下面是对 Python 中 collections 模块中几个常用类（namedtuple、deque、defaultdict、OrderedDict、ChainMap 和 Counter）的详细总结及其应用场景说明，每个例子都附有代码示例：

1、namedtuple

功能说明

namedtuple 用于创建一个轻量级的不可变对象，与元组类似，但可以通过属性来访问各个元素，从而让代码更具可读性和可维护性。

应用场景

适用于需要存储少量数据且数据结构固定的场景，比如表示二维坐标、记录条目或配置项等。比如在处理几何图形时，可以用 namedtuple 表示点（Point）或矩形（Rectangle）。

示例代码

from collections import namedtuple

# 定义一个表示二维点的 namedtuple
Point = namedtuple("Point", ["x", "y"])
p = Point(10, 20)

print(p.x)  # 输出：10
print(p.y)  # 输出：20

2、deque

功能说明

deque（双端队列）提供了在两端高效追加和弹出操作的功能，适用于需要频繁在队列两端进行操作的场景。

应用场景

适用于实现队列、栈或者滑动窗口算法。例如，使用 deque 实现广度优先搜索（BFS）时，可以从队列左侧弹出元素并从右侧追加新节点。

示例代码

from collections import deque

# 创建一个 deque，并进行左右两端的操作
dq = deque([1, 2, 3])
dq.append(4)         # 在右侧追加
dq.appendleft(0)     # 在左侧追加

print(dq)  # 输出：deque([0, 1, 2, 3, 4])

# 从两端弹出元素
print(dq.pop())      # 输出：4
print(dq.popleft())  # 输出：0

3、defaultdict

功能说明

defaultdict 是 dict 的子类，它在访问不存在的键时，会自动创建一个默认值，而不会抛出 KeyError。默认值由工厂函数（如 int、list、set 等）提供。

应用场景

常用于计数、分组、聚合数据等场景。例如，在统计单词出现次数时，可以用 defaultdict(int) 来自动初始化计数为 0。

示例代码

from collections import defaultdict

# 使用 defaultdict 统计单词出现次数
words = ["apple", "banana", "apple", "orange", "banana", "apple"]
word_count = defaultdict(int)

for word in words:
    word_count[word] += 1

print(dict(word_count))
# 输出：{'apple': 3, 'banana': 2, 'orange': 1}

4、OrderedDict

功能说明

OrderedDict 是字典的一个子类，它记录了键值对插入的顺序（在 Python 3.7 以后，内置 dict 已经保持插入顺序，但 OrderedDict 依然提供一些额外方法，如 move_to_end）。

应用场景

适用于需要对字典的顺序进行操作或依赖插入顺序的场景，如实现 LRU 缓存机制、记录操作历史记录等。

示例代码

from collections import OrderedDict

od = OrderedDict()
od["apple"] = 1
od["banana"] = 2
od["orange"] = 3

print(list(od.items()))
# 输出：[('apple', 1), ('banana', 2), ('orange', 3)]

# 使用 move_to_end 调整顺序
od.move_to_end("banana")
print(list(od.items()))
# 输出：[('apple', 1), ('orange', 3), ('banana', 2)]

5、ChainMap

功能说明

合并多个字典，按顺序查找键。

应用场景

多层配置优先级、变量作用域链。

示例代码

from collections import ChainMap

# 两个字典，后者会作为备用数据源
dict1 = {"a": 1, "b": 2}
dict2 = {"b": 3, "c": 4}

cm = ChainMap(dict1, dict2)
print(cm["a"])  # 输出：1，来自 dict1
print(cm["b"])  # 输出：2，dict1 中的 b 优先于 dict2
print(cm["c"])  # 输出：4，来自 dict2

6、Counter

功能说明

Counter 是一个专门用于计数的容器，返回一个字典对象，键是元素，值是出现的次数。它提供了常用的计数操作和统计功能。

应用场景

适用于统计数据频率，比如统计列表中各元素的出现次数，分析文本中的单词频率等。

示例代码

from collections import Counter

# 统计列表中每个元素出现的次数
items = ["apple", "banana", "apple", "orange", "banana", "apple"]
count = Counter(items)

print(count)
# 输出：Counter({'apple': 3, 'banana': 2, 'orange': 1})

# 常见操作：获取出现频率最高的两个元素
print(count.most_common(2))
# 输出：[('apple', 3), ('banana', 2)]

itertools

一、无限迭代器 (Infinite Iterators)

  1. itertools.count(start=0, step=1)

    • 用途: 生成无限递增的数值序列。

    • 示例:

      import itertools
for num in itertools.count(10, 2):
    if num > 20: break
    print(num)  # 输出: 10, 12, 14, 16, 18, 20

  2. itertools.cycle(iterable)

    • 用途: 无限循环重复给定的可迭代对象。

    • 示例:

      c = itertools.cycle('AB')
print([next(c) for _ in range(4)])  # 输出: ['A', 'B', 'A', 'B']

  3. itertools.repeat(obj, times=None)

    • 用途: 重复生成对象，可指定次数或无限重复。

    • 示例:

      print(list(itertools.repeat('X', 3)))  # 输出: ['X', 'X', 'X']

二、组合生成器(Combinatoric Iterators)

  1. itertools.product(*iterables, repeat=1)

    • 用途: 计算多个可迭代对象的笛卡尔积（类似嵌套循环）。

    • 示例:

      prod = itertools.product('AB', [1,2])
print(list(prod))  # 输出: [('A',1), ('A',2), ('B',1), ('B',2)]

  2. itertools.permutations(iterable, r=None)

    • 用途: 生成所有可能的排列（顺序敏感）。

    • 示例:

      perms = itertools.permutations('ABC', 2)
print(list(perms))  # 输出: [('A','B'), ('A','C'), ('B','A'), ...]

  3. itertools.combinations(iterable, r)

    • 用途: 生成所有可能的组合（顺序不敏感）。

    • 示例:

      combs = itertools.combinations('ABC', 2)
print(list(combs))  # 输出: [('A','B'), ('A','C'), ('B','C')]

  4. itertools.combinations_with_replacement(iterable, r)

    • 用途: 允许元素重复的组合。

    • 示例:

      cwr = itertools.combinations_with_replacement('AB', 2)
print(list(cwr))  # 输出: [('A','A'), ('A','B'), ('B','B')]

三、迭代器操作工具

  1. itertools.chain(*iterables)

    • 用途: 将多个可迭代对象连接成一个迭代器。

    • 示例:

      chained = itertools.chain('AB', [1,2])
print(list(chained))  # 输出: ['A', 'B', 1, 2]

  2. itertools.zip_longest(*iterables, fillvalue=None)

    • 用途: 类似 zip，但以最长可迭代对象为准，缺失值用 fillvalue 填充。

    • 示例:

      zipped = itertools.zip_longest('AB', [1,2,3], fillvalue='X')
print(list(zipped))  # 输出: [('A',1), ('B',2), ('X',3)]

  3. itertools.islice(iterable, start, stop[, step])

    • 用途: 对迭代器进行切片，类似列表切片。

    • 示例:

      sliced = itertools.islice(itertools.count(), 5, 10, 2)
print(list(sliced))  # 输出: [5, 7, 9]

四、分组与聚合

  1. itertools.groupby(iterable, key=None)

    • 用途: 根据 key 函数对元素分组，需先排序（分组前必须排序！）。

    • 示例:

      data = sorted([('a',1), ('b',2), ('a',3)], key=lambda x: x[0])
for key, group in itertools.groupby(data, key=lambda x: x[0]):
    print(key, list(group))  # 输出: 'a' [('a',1), ('a',3)]; 'b' [('b',2)]

  2. itertools.accumulate(iterable, func=operator.add)

    • 用途: 生成累积计算结果（默认累加）。

    • 示例:

      acc = itertools.accumulate([1,2,3,4], lambda a,b: a*b)
print(list(acc))  # 输出: [1, 2, 6, 24]

五、筛选工具

  1. itertools.filterfalse(predicate, iterable)

    • 用途: 筛选不满足 predicate 的元素。

    • 示例:

      ff = itertools.filterfalse(lambda x: x%2==0, [1,2,3,4])
print(list(ff))  # 输出: [1, 3]

  2. itertools.takewhile(predicate, iterable)

    • 用途: 从头部开始取元素，直到条件不满足。

    • 示例:

      tw = itertools.takewhile(lambda x: x<5, [1,3,5,2])
print(list(tw))  # 输出: [1, 3]

  3. itertools.dropwhile(predicate, iterable)

    • 用途: 跳过元素，直到条件不满足，之后保留所有元素。

    • 示例:

      dw = itertools.dropwhile(lambda x: x<5, [1,3,6,2])
print(list(dw))  # 输出: [6, 2]

典型应用场景

  • 高效处理大数据：避免一次性加载所有数据到内存（如 islice、chain）。
  • 复杂迭代逻辑：替代多层嵌套循环（如 product、combinations）。
  • 数据分组与聚合（如 groupby、accumulate）。

正则表达式

常用正则符号速查

符号说明
.匹配任意字符（除换行符）
\d匹配数字（等价于 [0-9]）
\w匹配字母、数字、下划线
*匹配前一个字符 0 次或多次
+匹配前一个字符 1 次或多次
?匹配前一个字符 0 次或 1 次
{n}匹配前一个字符恰好 n 次
^匹配字符串开头
$匹配字符串结尾
[...]匹配括号内的任意字符

1. re.match()

用途：从字符串开头匹配模式。

场景：验证字符串是否以特定模式开头（如协议头、固定格式）。

示例：

import re

text = "2023-08-01 Log: System started"
pattern = r"\d{4}-\d{2}-\d{2}"  # 匹配日期格式

result = re.match(pattern, text)
if result:
    print("日期:", result.group())  # 输出: 日期: 2023-08-01
else:
    print("未匹配到开头日期")

2. re.search()

用途：在整个字符串中查找第一个匹配的模式。

场景：提取第一个符合条件的子串（如提取邮箱、URL）。

示例：

text = "Contact: support@example.com, sales@test.org"
pattern = r"\b[\w.-]+@[\w.-]+\.\w+\b"  # 匹配邮箱

result = re.search(pattern, text)
if result:
    print("第一个邮箱:", result.group())  # 输出: support@example.com

3. re.findall()

用途：返回所有匹配的字符串列表。

场景：批量提取符合条件的内容（如所有电话号码、关键词）。

示例：

text = "Prices: $10, ¥500, €20, $30"
pattern = r"\$(\d+)"  # 匹配美元金额（带分组）

results = re.findall(pattern, text)
print("美元金额:", results)  # 输出: ['10', '30']

4. re.finditer()

用途：返回所有匹配的迭代器（适合处理大文本）。

场景：逐条处理匹配结果（如日志分析）。

示例：

text = "IDs: A123, B456, C789"
pattern = r"[A-Z]\d{3}"

for match in re.finditer(pattern, text):
    print("找到ID:", match.group(), "位置:", match.span())
# 输出:
# 找到ID: A123 位置: (5, 9)
# 找到ID: B456 位置: (10, 14)
# 找到ID: C789 位置: (15, 19)

5. re.sub()

用途：替换匹配的字符串。

场景：数据清洗、脱敏（如替换手机号中间四位为****）。

示例：

text = "Phone: 138-1234-5678, 139-8765-4321"
pattern = r"(\d{3})-(\d{4})-(\d{4})"
replacement = r"\1-****-\3"  # 保留前3位和后4位

new_text = re.sub(pattern, replacement, text)
print(new_text)  # 输出: Phone: 138-****-5678, 139-****-4321

6. re.split()

用途：按模式分割字符串。

场景：复杂分隔符拆分（如混合符号分割数据）。

示例：

text = "Apple,Banana;Cherry|Orange"
pattern = r"[,;|]"  # 按逗号、分号、竖线分割

parts = re.split(pattern, text)
print(parts)  # 输出: ['Apple', 'Banana', 'Cherry', 'Orange']

7. 编译正则表达式（re.compile()）

用途：预编译正则表达式，提高重复使用效率。

场景：频繁使用同一模式时（如循环中多次匹配）。

示例：

pattern = re.compile(r"\b[A-Z]\w+\b")  # 匹配大写开头的单词
texts = ["Python is Good", "hello World"]

for text in texts:
    matches = pattern.findall(text)
    print(matches)
# 输出:
# ['Python', 'Good']
# ['World']

8. 分组与引用

用途：提取子模式或替换时引用分组。

场景：结构化数据提取（如日志中的日期、错误码）。

示例：

text = "Date: 2023-08-01, Error: 404"
pattern = r"Date: (\d{4}-\d{2}-\d{2}), Error: (\d+)"

match = re.search(pattern, text)
if match:
    print("日期:", match.group(1))   # 输出: 2023-08-01
    print("错误码:", match.group(2)) # 输出: 404

9. 标志参数（Flags）

用途：控制匹配行为（如忽略大小写、多行模式）。

场景：灵活匹配（如跨行匹配、大小写不敏感）。

示例：

text = "Line 1\nLine 2\nline 3"
pattern = r"^line"  # 默认不跨行匹配

# 使用 re.MULTILINE（多行模式）和 re.IGNORECASE（忽略大小写）
matches = re.findall(pattern, text, flags=re.M | re.I)
print(matches)  # 输出: ['Line', 'line']

总结

  • 验证开头：re.match()
  • 查找第一个匹配：re.search()
  • 批量提取：re.findall() / re.finditer()
  • 替换内容：re.sub()
  • 复杂分割：re.split()
  • 提高效率：预编译正则表达式（re.compile()）
  • 精细控制：分组、标志参数（flags）

示例综合应用：

# 从日志中提取所有IP和状态码
log = """
192.168.1.1 - GET /api 200
10.0.0.2 - POST /login 404
"""

pattern = re.compile(r"(\d+\.\d+\.\d+\.\d+).*?(\d{3})")
for ip, code in pattern.findall(log):
    print(f"IP: {ip}, 状态码: {code}")
# 输出:
# IP: 192.168.1.1, 状态码: 200
# IP: 10.0.0.2, 状态码: 404

异步 io

异步 I/O（Async IO）是 Python 中处理并发编程的核心机制，通过 事件循环 和 协程 实现非阻塞操作，尤其适合 I/O 密集型任务。

核心概念

  1. 协程 (Coroutine)
    • 用 async def 定义的函数，通过 await 暂停执行，让出控制权。
  2. 事件循环 (Event Loop)
    • 调度协程的执行，管理 I/O 操作和回调。
  3. 异步任务 (Task)
    • 通过 asyncio.create_task() 将协程包装为可调度的任务。
  4. 非阻塞
    • 协程在等待 I/O 时释放 CPU，允许其他任务执行。

关键技术点

  • async：定义异步函数
  • await：挂起协程，等待异步操作完成
  • asyncio.run()：启动事件循环

实例演示

1. 基础异步函数

import asyncio

async def say_hello():
    print("Hello")
    await asyncio.sleep(1)  # 模拟I/O等待
    print("World")

# 运行协程
asyncio.run(say_hello())

2. 并发网络请求

使用 aiohttp 代替同步的 requests：

import aiohttp
import asyncio

async def fetch(url):
    async with aiohttp.ClientSession() as session:
        async with session.get(url) as response:
            return await response.text()

async def main():
    urls = ["http://example.com"] * 3
    tasks = [fetch(url) for url in urls]
    results = await asyncio.gather(*tasks)
    print(f"Got {len(results)} responses")

asyncio.run(main())

3. 异步文件操作

使用 aiofiles 处理文件：

import aiofiles
import asyncio

async def write_file():
    async with aiofiles.open('test.txt', 'w') as f:
        await f.write("Async file write")

asyncio.run(write_file())

4. 多个任务并发

async def task1():
    await asyncio.sleep(2)
    print("Task1 done")

async def task2():
    await asyncio.sleep(1)
    print("Task2 done")

async def main():
    await asyncio.gather(task1(), task2())

asyncio.run(main())
# 输出顺序：Task2 done → Task1 done

注意事项

  1. 避免在协程中使用阻塞操作（如 time.sleep()）
  2. CPU 密集型任务仍需用 multiprocessing
  3. 异步生态需配合专用库（如 aiohttp, aiomysql）

架构流程图
+-------------------+     +-----------------+     +-----------------+
|      Spider       |     |     Engine      |     |   Scheduler     |
| (生成初始Request) | --> | (协调数据流)    | --> | (管理请求队列)  |
+-------------------+     +-----------------+     +-----------------+
       ^                         |                         |
       |                         v                         v
+-------------------+     +-----------------+     +-----------------+
|  Spider Middleware| <-- | Downloader      | <-- | Downloader      |
| (处理输入/输出)   |     | (发送请求)       |     | Middleware      |
+-------------------+     +-----------------+     +-----------------+
       ^                         |
       |                         v
+-------------------+     +-----------------+     +-----------------+
| Item Pipeline     | <-- | Spider解析响应  | --> | 生成新Request   |
| (处理Item)        |     | (生成Item/Request)|   | (循环流程)      |
+-------------------+     +-----------------+     +-----------------+
核心组件交互流程
  1. Spider
    • 生成初始 Request 对象（如 start_requests() 方法）。
    • 将 Request 提交给 Engine。
  2. Engine
    • 接收 Request，将其传递给 Scheduler 排队。
    • 从 Scheduler 获取下一个待处理的 Request。
  3. Scheduler
    • 管理请求队列（优先级、去重等）。
    • 将 Request 返回给 Engine。
  4. Downloader Middleware
    • 在请求发送前处理 Request（如添加代理、修改 Headers）。
    • 在响应返回后处理 Response（如处理重定向、异常）。
  5. Downloader
    • 通过 HTTP 下载页面，生成 Response 对象。
    • 将 Response 返回给 Engine。
  6. Spider Middleware
    • 在 Response 到达 Spider 前预处理（如过滤无效响应）。
    • 在 Spider 生成 Item 或新 Request 后处理（如数据校验）。
  7. Spider 解析
    • 解析 Response，生成 Item（数据）或新 Request（分页/深度抓取）。
    • Item 发送到 Item Pipeline，Request 发送回 Engine。
  8. Item Pipeline
    • 处理 Item（清洗、验证、存储到数据库等）。
关键数据流
  1. 请求流Spider → Engine → Scheduler → Engine → Downloader Middleware → Downloader
  2. 响应流Downloader → Downloader Middleware → Engine → Spider Middleware → Spider
  3. 数据流Spider → Item PipelineSpider → Engine → Scheduler（新请求）
