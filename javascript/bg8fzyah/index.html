基本数据类型（Primitive Types）

  1. number 数字类型
let age = 25; // 整数
let price = 99.95; // 浮点数
let hex = 0xff; // 十六进制 (255)
let infinity = 1 / 0; // Infinity（无穷大）

特性：

  • 所有数字均为 64 位双精度浮点数

  • 特殊值：NaN（非数字）、Infinity（无穷大）

  • 精度问题（经典陷阱）：

    0.1 + 0.2 === 0.3; // false → 实际结果 0.30000000000000004
  1. string 字符串类型
let str1 = "Hello"; // 单引号
let str2 = "World"; // 双引号
let template = `Hi ${str1}`; // 模板字符串（ES6）

特性：

  • 不可变性（每次操作生成新字符串）

  • 支持 Unicode 字符：

    let emoji = "😊";
  1. boolean 布尔类型
let isActive = true;
let isAdmin = false;

真值判断规则：

  • 假值（falsey values）：false, 0, "", null, undefined, NaN
  • 其他所有值均为真值
  1. null 空值
let empty = null; // 表示"无值"（需主动赋值）

特性：

  • typeof null → "object"（历史遗留问题）
  1. undefined 未定义
let x; // 默认值 undefined
let y = void 0; // 显式获取 undefined

特性：

  • 变量未初始化时的默认值
  • 函数无返回值时返回 undefined
  1. symbol 唯一值（ES6+）
const id1 = Symbol("id");
const id2 = Symbol("id");
console.log(id1 === id2); // false → 唯一性

用途：

  • 创建对象唯一键名
  • 定义私有属性
  1. bigint 大整数（ES2020+）
const bigNum = 9007199254740991n; // 后缀n
console.log(bigNum + 1n); // 9007199254740992n

特性：

  • 精确表示大于 2^53-1 的整数
  • 不能与普通 number 混合运算

编程风格

一、基础代码规范

1. 命名约定

  • 变量/函数：小驼峰命名法（calculateTotalPrice）
  • 类/构造函数：大驼峰命名法（class UserModel）
  • 常量：全大写+下划线（const MAX_ITEMS = 100）
  • 布尔值：以 is/has/can 开头（isLoading, hasPermission）
// 好的命名示例
const userList = [];
function formatCurrency(amount) {
  /*...*/
}
class NetworkRequest {
  /*...*/
}

2. 代码格式

  • 缩进：统一使用 2 或 4 空格（禁止 Tab）

  • 行宽：建议不超过 80-120 字符

  • 分号：强制显式添加（避免 ASI 陷阱）

  • 空格规范：

    // 运算符两侧空格
const sum = 1 + 2;

// 函数参数间空格
function createUser(name, age) {
  /*...*/
}

// 对象字面量冒号后空格
const config = { port: 3000, env: "dev" };

二、现代语法优先

1. 变量声明

  • 弃用 var：优先使用 const，需要修改时用 let

    // Bad
var count = 0;

// Good
let count = 0;
const MAX_RETRIES = 3;

2. 箭头函数

  • 简化回调函数，保留 function 用于需要 this 绑定的场景

    // 传统写法
[1, 2, 3].map(function (num) {
  return num * 2;
});

// 现代写法
[1, 2, 3].map((num) => num * 2);

3. 模板字符串

  • 替代字符串拼接（支持多行文本）

    const message = `用户 ${userName} 
的余额为：${balance.toFixed(2)} 元`;

4. 解构赋值

  • 简化对象/数组取值

    // 对象解构
const { id, name } = user;

// 函数参数解构
function render({ width = 100, height = 200 }) {
  /*...*/
}

三、代码组织原则

1. 函数设计

  • 单一职责：每个函数只做一件事

  • 长度限制：建议不超过 20 行

  • 参数控制：不超过 3 个参数，复杂对象用解构

    // Bad
function processData(data, isValidate, callback, options) {
  /*...*/
}

// Good
function processData({ data, validate = true, options }) {
  /*...*/
}

2. 条件判断优化

  • 提前返回：减少嵌套层级

    // 嵌套写法
function checkAccess(user) {
  if (user) {
    if (user.role === "admin") {
      return true;
    }
  }
  return false;
}

// 提前返回
function checkAccess(user) {
  if (!user) return false;
  if (user.role === "admin") return true;
  return false;
}

3. 异步处理规范

  • 统一使用 async/await：替代回调地狱

    // Bad: 回调嵌套
fetchData((err, data) => {
  if (err) handleError();
  processData(data, () => {
    /*...*/
  });
});

// Good: async/await
async function loadData() {
  try {
    const data = await fetchData();
    await processData(data);
  } catch (err) {
    handleError(err);
  }
}

四、防御性编程

1. 类型检查

  • 使用 typeof/instanceof 或 TypeScript

    function sum(a, b) {
  if (typeof a !== "number" || typeof b !== "number") {
    throw new TypeError("参数必须为数字");
  }
  return a + b;
}

2. 空值处理

  • 可选链操作符（?.）与空值合并（??）

    // 旧写法
const value = (obj && obj.prop) || "default";

// 新写法
const value = obj?.prop ?? "default";

3. 不可变模式

  • 避免直接修改原始数据

    // Bad: 直接修改
const items = [1, 2, 3];
items.push(4);

// Good: 创建新数组
const newItems = [...items, 4];

六、性能敏感区规范

1. 循环优化

  • 避免在循环内创建函数/重复计算

    // Bad
for (let i = 0; i < data.length; i++) {
  data[i].id = generateId(); // 每次循环调用函数
}

// Good
const idGenerator = generateId(); // 提前初始化
for (let i = 0, len = data.length; i < len; i++) {
  data[i].id = idGenerator.next();
}

2. DOM 操作

  • 批量更新减少重绘

    // Bad: 多次修改
list.forEach((item) => {
  document.body.appendChild(createElement(item));
});

// Good: 使用文档片段
const fragment = document.createDocumentFragment();
list.forEach((item) => fragment.appendChild(createElement(item)));
document.body.appendChild(fragment);

七、注释与文档

1. 注释原则

  • 避免解释 "是什么"，专注说明 "为什么"

  • 使用 JSDoc 标注重要函数：

    /**
 * 计算订单折扣价格
 * @param {number} price - 原始价格
 * @param {number} discountRate - 折扣率 (0-1)
 * @returns {number} 折扣后价格
 */
function calculateDiscount(price, discountRate) {
  return price * (1 - discountRate);
}

2. 代码自文档化

  • 通过命名和结构提升可读性

    // Bad
function proc(d) {
  /*...*/
} // 无意义缩写

// Good
function processDeliveryOrder(orderData) {
  /*...*/
}

循环

一、基础循环类型

1. for 循环

  • 用途：精确控制循环次数，适合已知迭代次数的场景

  • 语法：

    for (初始化; 条件; 迭代) {
  // 循环体
}

  • 示例：

    // 遍历数组（传统方式）
const arr = [10, 20, 30];
for (let i = 0; i < arr.length; i++) {
  console.log(arr[i]); // 10 → 20 → 30
}

2. while 循环

  • 用途：不确定循环次数时使用（先检查条件）

  • 语法：

    while (条件) {
  // 循环体
}

  • 示例：

    // 处理用户输入直到满足条件
let input;
while (input !== "exit") {
  input = prompt("输入 exit 退出:");
}

3. do...while 循环

  • 用途：至少执行一次循环体，再进行条件判断

  • 语法：

    do {
  // 循环体
} while (条件);

  • 示例：

    // 生成随机数直到大于0.5
let num;
do {
  num = Math.random();
} while (num <= 0.5);

二、现代迭代循环

1. for...of 循环（ES6+）

  • 用途：遍历可迭代对象（数组、字符串、Map、Set 等）

  • 特点：直接获取元素值，无需索引

  • 示例：

    // 遍历数组（推荐方式）
const colors = ["red", "green", "blue"];
for (const color of colors) {
  console.log(color); // 'red' → 'green' → 'blue'
}

// 遍历字符串
for (const char of "Hello") {
  console.log(char); // 'H' → 'e' → 'l' → 'l' → 'o'
}

2. for...in 循环

  • 用途：遍历对象的可枚举属性（包括原型链上的属性）

  • 注意：数组遍历不推荐使用（可能得到非数字键）

  • 示例：

    // 遍历对象属性
const obj = { a: 1, b: 2 };
for (const key in obj) {
  console.log(`${key}: ${obj[key]}`); // 'a: 1' → 'b: 2'
}

三、高阶函数式循环

1. Array.forEach()

  • 用途：替代传统 for 循环，遍历数组元素

  • 特点：无法使用 break 或 return 终止循环

  • 示例：

    [1, 2, 3].forEach((num, index) => {
  console.log(`元素 ${num} 索引 ${index}`);
});

2. Array.map()

  • 用途：映射数组元素，返回新数组

  • 示例：

    const doubled = [1, 2, 3].map((num) => num * 2); // [2, 4, 6]

3. Array.filter()

  • 用途：过滤数组元素，返回符合条件的新数组

  • 示例：

    const evens = [1, 2, 3, 4].filter((num) => num % 2 === 0); // [2, 4]

四、循环控制语句

1. break

  • 用途：立即终止整个循环

  • 示例：

    for (let i = 0; i < 10; i++) {
  if (i === 5) break;
  console.log(i); // 0-4
}

2. continue

  • 用途：跳过当前迭代，进入下一次循环

  • 示例：

    for (let i = 0; i < 5; i++) {
  if (i === 2) continue;
  console.log(i); // 0,1,3,4
}

3. 标签语句

  • 用途：配合 break/continue 控制多层嵌套循环

  • 示例：

    outerLoop: for (let i = 0; i < 3; i++) {
  for (let j = 0; j < 3; j++) {
    if (i === 1 && j === 1) break outerLoop;
    console.log(i, j); // (0,0)(0,1)(0,2)(1,0)
  }
}

五、循环最佳实践

1. 循环选择指南

场景推荐方法
数组遍历for...of 或 Array.forEach()
对象遍历for...in + hasOwnProperty 检查
需要索引传统 for 循环
提前终止for 循环 + break

2. 性能优化技巧

  • 缓存数组长度（传统 for 循环时）：

    for (let i = 0, len = arr.length; i < len; i++) { ... }

  • 避免在循环内修改数组长度（导致不可预知行为）

  • 优先使用不可变方法（如 map/filter 代替循环内修改原数组）

3. 常见陷阱

  • for...in 遍历数组问题：

    Array.prototype.foo = "bar";
const arr = [1, 2, 3];
for (const key in arr) {
  console.log(key); // 0,1,2,foo （可能包含非数字键）
}

  • 异步循环问题（需结合 async/await）：

    // 错误方式：forEach 无法正确处理 async
[1, 2, 3].forEach(async (num) => {
  await someAsyncTask(num); // 不会按顺序执行
});

// 正确方式：for...of 循环
for (const num of [1, 2, 3]) {
  await someAsyncTask(num); // 顺序执行
}

六、特殊循环场景

1. 遍历 Map/Set

const map = new Map([['a', 1], ['b', 2]]);
for (const [key, value] of map) { ... }

const set = new Set([1, 2, 3]);
for (const value of set) { ... }

2. 迭代器协议

const customIterable = {
  [Symbol.iterator]: function* () {
    yield 1;
    yield 2;
    yield 3;
  },
};

for (const num of customIterable) {
  console.log(num); // 1 → 2 → 3
}

类型转换

一、显式转换

1. 转字符串

  • String()函数：将任意类型转为字符串

    String(42); // "42"
String(true); // "true"
String(null); // "null"

  • toString()方法：

    (42).toString(); // "42"
[1, 2].toString(); // "1,2"（数组转为逗号分隔字符串）

2. 转数值

  • Number()函数：

    Number("123"); // 123
Number("abc"); // NaN
Number(true); // 1

  • parseInt()/parseFloat()：

    parseInt("123.45"); // 123
parseFloat("123.45"); // 123.45

  • 一元加号+：

    +"123"; // 123
+"abc"; // NaN

3. 转布尔值

  • Boolean()函数：

    Boolean(""); // false（空字符串）
Boolean(0); // false
Boolean("hello"); // true（非空字符串）
Boolean({}); // true（对象）

二、隐式转换

1. 运算符触发

  • +运算符：优先拼接字符串

    "5" + 3; // "53"（数字转字符串）
5 + "3"; // "53"

  • -、*、/等算术运算符：转为数值

    "5" - 2; // 3（字符串转数字）
true * 2; // 2（布尔值转1）

2. 逻辑上下文

  • 条件判断：自动转为布尔值

    if ("") {
  /* 不执行 */
}
if (1) {
  /* 执行 */
}

3. ==比较

  • 类型不匹配时隐式转换：

    "5" == 5; // true（字符串转数字）
null == undefined; // true

三、对象到原始值的转换

  1. ToPrimitive机制：

    • 优先调用valueOf()，若返回非原始值则调用toString()
    • 数组转字符串：[1,2].toString() → "1,2"
    • 对象转默认值：{} → "[object Object]"

  2. Symbol.toPrimitive（自定义转换逻辑）：

    const obj = {
  [Symbol.toPrimitive](hint) {
    return hint === "number" ? 42 : "foo";
  },
};
console.log(obj + 1); // "foo1"

四、注意事项

  1. typeof的局限性：

    typeof null; // "object"（历史遗留问题）
typeof []; // "object"

  2. NaN的特殊性：

    NaN === NaN; // false
isNaN("abc"); // true（需显式检测）
Number.isNaN("abc"); // false

  3. 避免==隐式转换：推荐使用===严格比较。

总结

  • 显式转换：通过String()、Number()、Boolean()等函数主动控制。
  • 隐式转换：由运算符或上下文触发，需警惕+拼接和==比较的陷阱。
  • 对象转换：依赖ToPrimitive机制，可通过valueOf()和toString()覆盖逻辑。

四、Date（日期）

核心操作

四、高级异步模式

1. 并发控制

// 限制并发数为3
async function parallel(tasks, concurrency = 3) {
  const results = [];
  const executing = new Set();

  for (const task of tasks) {
    const p = task().then((res) => {
      executing.delete(p);
      return res;
    });
    executing.add(p);
    results.push(p);

    if (executing.size >= concurrency) {
      await Promise.race(executing);
    }
  }
  return Promise.all(results);
}

2. 取消异步操作

function cancellable(fn) {
  let cancel;
  const promise = new Promise((resolve, reject) => {
    cancel = () => reject(new Error("Cancelled"));
    fn(resolve, reject);
  });
  return { promise, cancel };
}

const { promise, cancel } = cancellable((resolve) => {
  setTimeout(() => resolve("Done"), 1000);
});
cancel(); // 中止操作

async function withProgress(promise, onProgress) {

    progress = Math.min(progress + 10, 90);
    onProgress(progress);

  try {
    const result = await promise;
    clearInterval(id);
    onProgress(100);
    return result;
  } catch (err) {
    clearInterval(id);
    throw err;
  }
}

DOM

1. 什么是 DOM？

DOM 是 HTML 和 XML 文档的编程接口，它将文档表示为一个节点树（称为 DOM 树）。每个节点代表文档中的一部分，例如元素、属性或文本。通过 DOM，JavaScript 可以访问和操作这些节点，从而改变网页的内容和结构。

简单来说，DOM 是浏览器提供的一个 API，允许 JavaScript 与 HTML 文档进行交互。

2. DOM 树结构

HTML 文档可以被看作是一个树形结构，根节点是document对象，代表整个 HTML 文档。document对象下有子节点，例如<html>元素，<html>下又有<head>和<body>等子节点。

示例：以下是一个简单的 HTML 文档及其对应的 DOM 树：

<!DOCTYPE html>
<html lang="en">
  <head>
    <title>DOM Example</title>
  </head>
  <body>
    <h1>Hello, World!</h1>
    <p>This is a paragraph.</p>
  </body>
</html>

对应的 DOM 树结构：

document
└── html
    ├── head
    │   └── title
    │       └── "DOM Example"
    └── body
        ├── h1
        │   └── "Hello, World!"
        └── p
            └── "This is a paragraph."

3. DOM 节点类型

DOM 树中的节点有多种类型，常见的包括：

  • 文档节点（Document Node）：代表整个文档，通常是document对象。
  • 元素节点（Element Node）：代表 HTML 中的标签，如<div>、<p>、<h1>等。
  • 文本节点（Text Node）：代表元素内的文本内容。
  • 属性节点（Attribute Node）：代表元素的属性，如id、class等。

4. DOM 操作

通过 DOM，JavaScript 可以执行以下操作：

  • 访问节点：查找和选择 DOM 树中的节点。
  • 修改节点：改变节点的内容、属性或样式。
  • 创建和删除节点：动态地添加或移除 DOM 树中的节点。

4.1 访问节点

JavaScript 提供了多种方法来访问 DOM 节点，常见的方法包括：

  • getElementById：通过元素的id属性获取元素。
  • getElementsByClassName：通过元素的class属性获取元素集合。
  • getElementsByTagName：通过标签名获取元素集合。
  • querySelector：使用 CSS 选择器获取第一个匹配的元素。
  • querySelectorAll：使用 CSS 选择器获取所有匹配的元素。

示例：

// 获取id为"myDiv"的元素
const div = document.getElementById("myDiv");

// 获取所有class为"item"的元素
const items = document.getElementsByClassName("item");

// 获取所有<p>元素
const paragraphs = document.getElementsByTagName("p");

// 获取第一个class为"item"的元素
const firstItem = document.querySelector(".item");

// 获取所有class为"item"的元素
const allItems = document.querySelectorAll(".item");

4.2 修改节点

你可以修改节点的内容、属性或样式。

  • 修改内容：
    • innerHTML：设置或获取元素的 HTML 内容。
    • textContent：设置或获取元素的文本内容。
  • 修改属性：
    • setAttribute：设置元素的属性。
    • getAttribute：获取元素的属性。
    • removeAttribute：移除元素的属性。
  • 修改样式：
    • style属性：直接设置 CSS 样式。

示例：

// 修改id为"myDiv"的元素的文本内容
const div = document.getElementById("myDiv");
div.textContent = "New text content";

// 修改id为"myDiv"的元素的HTML内容
div.innerHTML = "<p>New paragraph</p>";

// 设置id为"myDiv"的元素的class属性
div.setAttribute("class", "newClass");

// 获取id为"myDiv"的元素的class属性
const className = div.getAttribute("class");

// 移除id为"myDiv"的元素的class属性
div.removeAttribute("class");

// 修改id为"myDiv"的元素的背景颜色
div.style.backgroundColor = "blue";

4.3 创建和删除节点

你可以动态地创建新节点并添加到 DOM 树中，或者删除现有的节点。

  • 创建节点：
    • createElement：创建一个新元素。
    • createTextNode：创建一个文本节点。
  • 添加节点：
    • appendChild：将一个节点添加到另一个节点的子节点列表的末尾。
    • insertBefore：在指定节点之前插入一个新节点。
  • 删除节点：
    • removeChild：从父节点中移除一个子节点。

示例：

// 创建一个新的<p>元素
const newParagraph = document.createElement("p");
newParagraph.textContent = "This is a new paragraph.";

// 将新<p>元素添加到id为"myDiv"的元素中
const div = document.getElementById("myDiv");
div.appendChild(newParagraph);

// 在id为"myDiv"的元素中的第一个子节点之前插入一个新<h2>元素
const newHeading = document.createElement("h2");
newHeading.textContent = "New Heading";
div.insertBefore(newHeading, div.firstChild);

// 移除id为"myDiv"的元素中的第一个子节点
if (div.firstChild) {
  div.removeChild(div.firstChild);
}

  • removeEventListener：移除事件监听器。

  alert("Button clicked!");
}
button.addEventListener("click", handleClick);
button.removeEventListener("click", handleClick);

6. DOM 遍历

DOM 提供了属性和方法来遍历 DOM 树，例如：

  • parentNode：获取节点的父节点。
  • childNodes：获取节点的所有子节点。
  • firstChild：获取节点的第一个子节点。
  • lastChild：获取节点的最后一个子节点。
  • nextSibling：获取节点的下一个兄弟节点。
  • previousSibling：获取节点的上一个兄弟节点。

事件

一、什么是事件？

事件是指发生在网页上的某种动作或状态变化，例如用户点击按钮、输入文本，或页面加载完成等。JavaScript 可以通过监听这些事件，并在事件发生时执行相应的代码（事件处理程序）来做出响应。

二、常见事件类型

JavaScript 支持多种事件类型，以下是一些常见的分类和示例：

  • 鼠标事件：

    • click：鼠标点击
    • dblclick：鼠标双击
    • mouseover：鼠标悬停
    • mouseout：鼠标移出

  • 键盘事件：

    • keydown：按键按下
    • keyup：按键松开

  • 表单事件：

    • submit：表单提交
    • change：表单元素值改变
    • focus：元素获得焦点
    • blur：元素失去焦点

  • 文档/窗口事件：

    • load：页面加载完成
    • resize：窗口大小改变
    • scroll：页面滚动

三、如何监听事件？

在 JavaScript 中，我们通常使用 addEventListener 方法为 DOM 元素添加事件监听器。这种方式灵活且推荐使用。它的基本语法是：

element.addEventListener(event, handler);
  • event：事件类型（如 'click'）
  • handler：事件发生时执行的函数

示例：点击事件

const button = document.getElementById("myButton");
button.addEventListener("click", function () {
  alert("按钮被点击了！");
});

在这个例子中，当用户点击 ID 为 myButton 的按钮时，会弹出一个提示框。

四、事件对象

每次事件发生时，浏览器都会创建一个事件对象（Event Object），并将其传递给事件处理函数。这个对象包含了事件的详细信息，例如触发事件的元素、鼠标位置等。

示例：获取事件信息

button.addEventListener("click", function (event) {
  console.log("事件类型:", event.type); // 输出 "click"
  console.log("触发元素:", event.target); // 输出按钮元素
});

五、事件冒泡与阻止

事件在 DOM 中传播时，默认会发生事件冒泡：从目标元素逐级向上传播到父元素。你可以用 event.stopPropagation() 停止传播，或者用 event.preventDefault() 阻止事件的默认行为（如链接跳转、表单提交）。

示例：阻止表单默认提交

const form = document.getElementById("myForm");
form.addEventListener("submit", function (event) {
  event.preventDefault(); // 阻止表单提交刷新页面
  console.log("表单已提交，但未刷新页面");
});

六、事件委托

当你有多个子元素需要监听事件时，可以通过事件委托在父元素上监听，利用事件冒泡来处理所有子元素的事件，这样可以减少代码量并提升性能。

示例：监听列表项点击

const list = document.getElementById("myList");
list.addEventListener("click", function (event) {
  if (event.target.tagName === "LI") {
    console.log("点击了列表项:", event.target.textContent);
  }
});

假设 HTML 是：

<ul id="myList">
  <li>项目 1</li>
  <li>项目 2</li>
  <li>项目 3</li>
</ul>

点击任意 <li> 时，控制台会输出对应的文本内容。

七、更多实用示例

1. 键盘事件

document.addEventListener("keydown", function (event) {
  console.log("按下的键是:", event.key);
});

按下键盘上的任意键，控制台会输出对应的按键名称。

2. 鼠标悬停效果

const element = document.getElementById("myElement");
element.addEventListener("mouseover", function () {
  element.style.backgroundColor = "yellow";
});
element.addEventListener("mouseout", function () {
  element.style.backgroundColor = "";
});

鼠标移到元素上时背景变为黄色，移出时恢复默认。

3. 页面加载事件

window.addEventListener("load", function () {
  console.log("页面加载完成");
});

页面完全加载后，控制台会输出提示。

总结

  • 事件是 JavaScript 实现动态交互的核心。
  • 使用 addEventListener 添加事件监听器，获取事件对象来了解事件细节。
  • 掌握事件冒泡和事件委托可以优化代码。
  • 通过 preventDefault 和 stopPropagation 控制事件行为。

浏览器模型

一、浏览器模型（BOM）核心对象

BOM 提供了与浏览器交互的接口，主要对象包括：

1. window 对象

作用：浏览器窗口的全局对象，所有全局变量和函数都是其属性/方法。

示例：

// 获取窗口尺寸
const width = window.innerWidth;
const height = window.innerHeight;

// 打开新窗口
window.open("https://example.com");

// 定时器
setTimeout(() => console.log("2秒后执行"), 2000);

2. navigator 对象

作用：获取浏览器和操作系统信息。

示例：

console.log(navigator.userAgent); // 浏览器标识
console.log(navigator.platform); // 操作系统类型
console.log(navigator.language); // 浏览器首选语言

3. location 对象

作用：操作 URL 信息。

示例：

location.href = "https://example.com"; // 跳转页面
console.log(location.search); // 获取 URL 查询参数
location.reload(); // 刷新页面

4. history 对象

作用：操作浏览器历史记录。

示例：

history.back(); // 后退
history.forward(); // 前进
history.pushState({}, "", "/new-page"); // 添加历史记录

5. screen 对象

作用：获取屏幕信息。

示例：

console.log(screen.width); // 屏幕宽度
console.log(screen.height); // 屏幕高度
console.log(screen.colorDepth); // 颜色深度

四、高级特性

1. Web Workers

是什么：Web Workers 是浏览器提供的后台线程技术，允许在独立于主线程的上下文中运行 JavaScript 脚本，避免阻塞页面渲染。
作用：

  • 执行耗时计算（如大数据处理、图像分析）。
  • 保持页面流畅，避免主线程卡顿。

应用场景：

  • 数据可视化（实时图表渲染）。
  • 视频/图像处理（如滤镜、格式转换）。
  • 复杂数学计算（物理模拟、加密算法）。

示例代码解析：

const worker = new Worker("worker.js"); // 创建 Worker，加载 worker.js 脚本
worker.postMessage(data); // 向 Worker 发送数据
worker.onmessage = (e) => {
  console.log("Worker 返回结果:", e.data); // 接收 Worker 计算结果
};

注意：Worker 不能直接操作 DOM，需通过 postMessage 与主线程通信。

2. Service Workers

是什么：Service Worker 是浏览器在后台运行的脚本，充当网络代理，可拦截和处理网络请求。
作用：

  • 实现离线缓存（如缓存关键资源，离线时仍可访问）。
  • 支持后台同步和推送通知。

应用场景：

  • 渐进式 Web 应用（PWA），如离线查看内容。
  • 加速重复访问（缓存静态资源）。
  • 后台数据同步（如邮件客户端）。

示例代码解析：

// 注册 Service Worker（需在 HTTPS 环境或 localhost）
navigator.serviceWorker.register("sw.js").then(() => {
  console.log("Service Worker 注册成功");
});

关键点：

  • Service Worker 有自己的生命周期（安装、激活、监听请求）。
  • 在 sw.js 中可监听 fetch 事件，控制缓存逻辑。

3. WebSocket

是什么：WebSocket 是一种基于 TCP 的双向通信协议，客户端和服务器可实时发送数据。
作用：

  • 实现低延迟的实时通信（相比 HTTP 轮询更高效）。
  • 支持全双工通信（双方可同时发送数据）。

应用场景：

  • 实时聊天应用（如在线客服）。
  • 多人在线游戏（同步玩家状态）。
  • 实时数据监控（股票行情、物流追踪）。

示例代码解析：

const socket = new WebSocket("wss://example.com"); // 使用加密的 WebSocket 协议（wss）
socket.onopen = () => {
  socket.send("连接已建立！"); // 发送数据
};
socket.onmessage = (e) => {
  console.log("收到消息:", e.data); // 接收服务器消息
};

注意：需处理连接断开（onclose）和错误（onerror）事件。

五、安全相关

1. CORS（跨域资源共享）

是什么：CORS 是一种机制，允许服务器声明哪些外部域名可以访问其资源，绕过浏览器的同源策略限制。
作用：

  • 安全地实现跨域请求（如不同域名的前后端分离项目）。
  • 控制资源的访问权限（如仅允许特定域名访问 API）。

应用场景：

  • 前端部署在 https://frontend.com，后端 API 在 https://api.com。
  • 第三方服务调用（如地图 API、支付接口）。

HTTP 头部示例：

Access-Control-Allow-Origin: https://yourdomain.com  # 允许指定域名
Access-Control-Allow-Methods: GET, POST, PUT        # 允许的 HTTP 方法
Access-Control-Allow-Headers: Content-Type          # 允许的请求头

关键点：

  • 简单请求（如 GET/POST）直接发送，复杂请求（如 PUT/DELETE）会先发送预检请求（OPTIONS）。

2. 内容安全策略（CSP）

是什么：CSP 通过白名单机制，限制网页中可以加载的资源（脚本、图片、字体等），防止 XSS 攻击。
作用：

  • 阻止恶意脚本执行（如注入的第三方脚本）。
  • 减少数据泄露风险（如限制图片只能从特定域名加载）。

应用场景：

  • 防止 XSS 攻击（如用户输入被恶意执行）。
  • 限制第三方资源（仅信任 CDN 或内部域名）。

HTML 示例：

<meta
  http-equiv="Content-Security-Policy"
  content="default-src 'self'; script-src 'self' https://trusted.cdn.com"
/>

策略解析：

  • default-src 'self'：默认仅允许加载同源资源。
  • script-src：限制脚本只能来自当前域名或可信 CDN。

其他指令：

  • img-src: 控制图片来源。
  • style-src: 控制 CSS 来源。
  • report-uri: 配置违规报告地址。

总结

  • 高级特性：提升性能和用户体验（后台计算、离线支持、实时通信）。
  • 安全机制：保护资源安全和用户隐私（跨域控制、攻击防护）。
    实际开发中需结合场景选择合适的技术，并遵循安全最佳实践。
